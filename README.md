# BERT Question Answering System

This repository presents an end-to-end question answering system built with DistilBERT and trained on the SQuAD dataset.

It implements a complete machine learning pipeline that covers the full lifecycle of an NLP model, from raw data processing to model training, evaluation, and deployment.

The system is designed to be reproducible and modular, making it easy to experiment locally with lightweight configurations while also scaling to full training setups on GPU.  

---
## Key Features
- **End-to-end ML pipeline** spanning data ingestion, preprocessing, training, evaluation, and inference
- **Fine-tuned DistilBERT model** for extractive question answering on SQuAD
- **Production-style API** for real-time inference
- **Config-driven design** for reproducibility and easy experimentation
- **Dynamic Padding**: efficient batching strategy that pads only to the longest sequence in a batch, reducing memory usage and improving training efficiency.
- **Sliding Window (Document Stride)** enables processing of long contexts by splitting them into overlapping chunks while preserving full context coverage.
- **Token-to-Span Alignment (Offset Mapping)** accurately maps character-level answers to token-level positions for supervised learning.

*Note: The implementation supports both lightweight local CPU runs (using dataset subsets) and full-scale training on GPU.

## API Usage

This project exposes a REST API using Flask for question-answering inference. Start the Flask server from the project root directory:

```bash
python -m app.api
```

The API will be available at http://127.0.0.1:5000

Interactive API documentation is available at:

http://127.0.0.1:5000/apidocs/

## Local Setup

1. Clone the repository:
```bash
git clone https://github.com/Khaghshenas/qa-bert-squad.git
cd qa-bert-squad
```

2. Create a Python virtual environment and install dependencies:

Create the virtual environment (only needed once):
```bash
python -m venv venv   # Windows
python3 -m venv venv # Linux / macOS
```
After the environment has been created, activate it:
```bash
venv\Scripts\Activate.ps1   # Windows (PowerShell)
source venv/bin/activate # Linux / macOS
```
Once the environment is activated, install the dependencies:
```bash
pip install -r requirements.txt
```

3. Download Dataset
```bash
python -m src.data.download_data
```
This downloads the SQuAD dataset to data/squad/.

4. Preprocess / Tokenize
```bash
python -m src.data.preprocess
```
- Tokenizes questions and contexts using DistilBERT tokenizer.
- Saves tokenized data for training.

5. Train Model
```bash
python -m src.training.train
```
- Fine-tunes DistilBERT on tokenized subset.
- Saves model and tokenizer to models/bert-qa/.

For demonstration, a small subset is used; full training is supported on GPU.

6. Evaluate Model
```bash
python -m src.evaluation.evaluate
```
Computes Exact Match (EM) and F1 score on validation subset.
